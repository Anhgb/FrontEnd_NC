# phu-xuan-react

Dự án xuyên suốt học phần Web Front End nâng cao

Trường Đại học Phú Xuân — Khoa Công nghệ thông tin

## Cài đặt và chạy

```bash
git clone https://github.com/Anhgb/FrontEnd_NC.git
cd phu-xuan-react
npm install
npm run dev
```

Mở trình duyệt tại http://localhost:5173

## Công nghệ

- React 19 + TypeScript
- Vite
- ESLint + Prettier
