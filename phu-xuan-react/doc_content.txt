LAB 2 — Nút yêu thích địa điểm
⏱ Thời gian: 20 phút    🎯 Mục tiêu: Dùng useState để lưu trạng thái yêu thích riêng cho từng thẻ    🌐 Lấy cảm hứng từ: Nút "Lưu" của Google Maps / biểu tượng trái tim của TripAdvisor
Trên Google Maps, mỗi địa điểm đều có nút "Lưu" hình ngôi sao hoặc trái tim — bấm vào để đánh dấu địa điểm yêu thích, bấm lại để bỏ đánh dấu. Đây là ví dụ kinh điển của State: mỗi thẻ tự quản lý trạng thái yêu thích của riêng nó, không liên quan gì đến các thẻ khác.
Bước 1 — Thêm state isFavorite vào AttractionCard
JSX — cập nhật src/components/AttractionCard.jsx
import { useState } from 'react';
function AttractionCard({ name, category, description, rating }) {
  const [isFavorite, setIsFavorite] = useState(false);
  function handleToggleFavorite() {
    setIsFavorite((prev) => !prev);
  }
  return (
    <div className="attraction-card">
      <button
        className="attraction-card__favorite"
        onClick={handleToggleFavorite}
      >
        {isFavorite ? '♥ Đã lưu' : '♡ Lưu địa điểm'}
      </button>
      <div className="attraction-card__badge">{category}</div>
      <h3>{name}</h3>
      <p>{description}</p>
      <span className="attraction-card__rating">⭐ {rating}</span>
    </div>
  );
}
export default AttractionCard;
Bước 2 — Đổi màu nút khi đã yêu thích
Dùng biểu thức điều kiện ngay trong className để đổi style động theo state, giống hiệu ứng "trái tim đỏ" khi đã lưu:
<button
  className={`attraction-card__favorite ${isFavorite ? 'is-active' : ''}`}
  onClick={handleToggleFavorite}
>
  {isFavorite ? '♥ Đã lưu' : '♡ Lưu địa điểm'}
</button>
💡 Vì sao mỗi thẻ có state riêng?
• Mỗi lần AttractionList gọi <AttractionCard />, React tạo ra một "bản thể" (instance) độc lập của component đó.
• useState bên trong mỗi bản thể hoàn toàn tách biệt — bấm yêu thích thẻ Đại Nội Huế sẽ không ảnh hưởng đến state của thẻ Chợ Đông Ba.
• Đây là lý do vì sao ta không cần một mảng "danh sách yêu thích" phức tạp ở component cha cho tính năng đơn giản này.

LAB 3 — Bộ lọc theo danh mục
⏱ Thời gian: 20 phút    🎯 Mục tiêu: Dùng state ở component cha để lọc danh sách hiển thị    🌐 Lấy cảm hứng từ: Thanh tab lọc danh mục của Shopee / Foody / Traveloka
Các sàn thương mại điện tử và ứng dụng du lịch luôn có thanh tab lọc phía trên danh sách (Tất cả / Điện tử / Thời trang..., hay Tất cả / Nhà hàng / Khách sạn...). Lab này xây dựng đúng cơ chế đó: state lưu danh mục đang chọn nằm ở component cha (App), và danh sách con chỉ hiển thị những gì khớp với danh mục đó.
Bước 1 — Lấy danh sách danh mục duy nhất từ dữ liệu
JSX — cập nhật src/App.jsx
import { useState } from 'react';
import AttractionList from './components/AttractionList';
import { attractions } from './data/attractions';
function App() {
  const [selectedCategory, setSelectedCategory] = useState('Tất cả');
  const categories = [
    'Tất cả',
    ...new Set(attractions.map((item) => item.category)),
  ];
  const filteredAttractions =
    selectedCategory === 'Tất cả'
      ? attractions
      : attractions.filter((item) => item.category === selectedCategory);
  return (
    <div className="app">
      <h1>Khám phá Huế</h1>
      <AttractionList attractions={filteredAttractions} />
    </div>
  );
}
export default App;

}

LAB 4 — Đánh giá bằng sao (Bài tập về nhà)
⏱ Thời gian: 30–40 phút (làm ở nhà)    🎯 Mục tiêu: Xây dựng thành phần đánh giá sao có thể chọn số sao bằng cách bấm chuột    🌐 Lấy cảm hứng từ: Hệ thống đánh giá sao của TripAdvisor / Google Reviews / Shopee
TripAdvisor và Google Reviews đều cho phép người dùng chấm điểm địa điểm bằng cách bấm vào số sao mong muốn (1 đến 5 sao). Lab này yêu cầu các bạn tự xây dựng thành phần StarRating theo đúng cơ chế đó, áp dụng vào từng thẻ AttractionCard.
Yêu cầu chi tiết
Tạo thành phần mới src/components/StarRating.jsx, có state riêng userRating (khởi tạo bằng 0).
Component hiển thị 5 ký hiệu sao (★ hoặc ☆) render bằng cách lặp qua mảng [1, 2, 3, 4, 5].
Khi người dùng bấm vào sao thứ n, tất cả các sao từ 1 đến n phải chuyển thành ★ (đã tô), các sao còn lại là ☆ (chưa tô).
Hiển thị thêm dòng chữ bên dưới, ví dụ: "Bạn đã đánh giá: 4/5 sao", cập nhật theo state userRating.
Đặt <StarRating /> bên trong AttractionCard, ngay dưới phần mô tả.
Gợi ý khung code — src/components/StarRating.jsx
import { useState } from 'react';
function StarRating() {
  const [userRating, setUserRating] = useState(0);
  const stars = [1, 2, 3, 4, 5];
  return (
    <div className="star-rating">
      {stars.map((starValue) => (
        <span
          key={starValue}
          className="star"
          onClick={() => setUserRating(starValue)}
        >
          {/* Gợi ý: dùng biểu thức điều kiện so sánh
             starValue <= userRating để chọn ★ hoặc ☆ */}
        </span>
      ))}
      <p>Bạn đã đánh giá: {userRating}/5 sao</p>
    </div>
  );
}
export default StarRating;
💡 Gợi ý cách tô sao theo giá trị đã chọn
• So sánh starValue <= userRating: nếu đúng thì hiển thị ★ (đã tô), nếu sai thì hiển thị ☆ (chưa tô).
• Có thể viết: {starValue <= userRating ? '★' : '☆'} ngay bên trong thẻ <span>.
• Đây chính là kỹ thuật kết xuất có điều kiện (conditional rendering) đã học ở Buổi 4, kết hợp với State của Buổi 5.

LAB 5 — Bộ đếm số lượng vé tham quan (Bài tập về nhà)
⏱ Thời gian: 30–40 phút (làm ở nhà)    🎯 Mục tiêu: Xây dựng bộ đếm số lượng có kiểm soát giới hạn, tính tổng tiền tự động    🌐 Lấy cảm hứng từ: Bộ đếm số lượng sản phẩm trong giỏ hàng Shopee / Tiki / Traveloka khi đặt vé
Khi đặt vé tham quan hoặc đặt mua sản phẩm trên các sàn thương mại điện tử, luôn có một bộ đếm số lượng dạng [ − ] [ số lượng ] [ + ], không cho phép giảm dưới 1 và thường giới hạn số lượng tối đa. Lab này yêu cầu xây dựng đúng thành phần đó cho tính năng "Đặt vé tham quan", đồng thời tự tính tổng tiền theo số lượng — kỹ năng sẽ dùng lại trực tiếp nếu nhóm chọn đề tài đồ án liên quan đến đặt vé, đặt phòng, hay đặt món ăn.
Yêu cầu chi tiết
Tạo thành phần mới src/components/TicketCounter.jsx, nhận vào props price (đơn giá vé, ví dụ 150000).
Component có state quantity, khởi tạo bằng 1.
Có 2 nút [ − ] và [ + ] để giảm/tăng quantity. Nút [ − ] không được cho phép giảm xuống dưới 1. Nút [ + ] không được cho phép tăng quá 10.
Hiển thị số lượng hiện tại ở giữa 2 nút.
Tính và hiển thị tổng tiền = price × quantity, định dạng có dấu chấm ngăn cách hàng nghìn (gợi ý dùng toLocaleString('vi-VN')).
Đặt <TicketCounter price={150000} /> vào bên trong AttractionCard của địa điểm Đại Nội Huế (địa điểm có bán vé thực tế).

• setQuantity((prev) => Math.max(1, prev - 1)) — đảm bảo kết quả không bao giờ nhỏ hơn 1.
• setQuantity((prev) => Math.min(10, prev + 1)) — đảm bảo kết quả không bao giờ lớn hơn 10.
• Đây là kỹ thuật rất phổ biến khi xử lý input số lượng trong các ứng dụng thương mại điện tử thực tế.

Tóm tắt những gì đã học trong buổi thực hành
Props giúp một component (như AttractionCard) tái sử dụng được cho nhiều dữ liệu khác nhau (Lab 1).
State cục bộ giúp mỗi thành phần con tự quản lý trạng thái riêng, độc lập với các thành phần cùng loại khác (Lab 2, Lab 4, Lab 5).
Khi nhiều thành phần cần dùng chung một trạng thái, phải nâng state lên thành phần cha gần nhất và truyền xuống qua props + callback (Lab 3).
Các tính năng tưởng chừng phức tạp trên ứng dụng thật (nút yêu thích, bộ lọc, đánh giá sao, bộ đếm giỏ hàng) đều được xây dựng chỉ từ hai khối kiến thức nền tảng: Props và State.
